## 1. 교육 모형의 한계 (피드백·문서에 명시할 문구)

- 이 앱의 시간·비용·손실 **토큰은 비교 학습용 가상 단위**이며 실제 가격, 시간, 환경 영향, 안전 결과를 나타내지 않는다.
- 등장하는 생산자·상품·장소는 모두 **가상**이며 실제 기업, 지역, 지도를 평가하지 않는다.
- 실제 유통은 여기서 다루지 않은 변수(계절, 재고, 물가, 노동)의 영향을 받는다. 교육 모형은 실제 세계 전체를 보장하지 않는다.

## 2. 미션별 정답·판정 규칙

토큰 표기는 `(시간, 비용, 손실)`이며 `null`은 "자료 없음"이다. 합계는 단계와 연결선을 모두 더한 값이고 `null`이 섞이면 합계도 `null`로 전파된다.

### route-strawberry-01 · 별빛 딸기 상자 (안내 미션)

- **학습 행동:** 생산→선별→운송→판매 순서 배열
- **승인 경로(정답):** `farm>sort>truck>store` — 합계 `(5, 4, 3)`
- **복수 정답:** 없음. 단계 순서가 계약이다.
- **필요 근거:** `stage-order-reason` (일의 차례 근거)
- **오개념 차단:** `shorter-is-always-better`(짧은 길 무조건 좋음)을 근거로 고르면 통과하지 않음.

### route-notebook-02 · 재생 종이 공책

- **학습 행동:** 원료→제조→창고→문구점 연결
- **승인 경로(복수 정답 둘 다):**
  - `raw-paper>factory>warehouse-a>stationery` — 합계 `(5, 4, 1)`
  - `raw-paper>factory>warehouse-b>stationery` — 합계 `(6, 3, 2)`
- **필요 근거:** `warehouse-tradeoff` (창고 A는 시간·손실 유리, 창고 B는 비용 유리)
- **오개념 차단:** `cheapest-is-best`(비용만 보면 무조건 좋음) 금지.

### route-delay-03 · 다리 점검으로 늦어진 운송

- **학습 행동:** 지연 토큰을 뒤 단계에 전파해 추적
- **기준 합계:** `(4, null, 1)` — 트럭 단계 비용이 자료 없음
- **조건 변화:** `bridge-check` — 연결선 `edge-bridge`의 시간 토큰 +3 → 합계 `(7, null, 1)`
- **판정 규칙:** 조건 변화 적용 필수. 근거 `time-propagates`와 `cost-still-unknown` 둘 다 필요.
- **오개념 차단:** `cost-becomes-zero`(자료 없으면 0으로 계산) 금지. 비용은 계속 "자료 없음"으로 남는다.

### route-package-04 · 포장 크기 고르기

- **학습 행동:** 포장 방식 한 조건을 바꿔 운송 횟수·토큰 비교
- **경로 합계:** 큰 상자 `(5, 4, 2)` / 작은 상자 `(7, 6, 0)`
- **승인 경로(정답):** `producer>package-small>truck-twice>store` (목표: 손실 토큰 줄이기)
- **조건 변화:** `switch-small-pack`, `switch-large-pack` (경로 교체형, 한 번에 하나만)
- **필요 근거:** `loss-goes-down` + `time-cost-go-up` — **장단점을 둘 다 기록해야 통과**
- **오개념 차단:** `small-pack-is-always-best` 금지.

### route-store-05 · 판매 장소 두 곳

- **학습 행동:** 거리·대기·손실 토큰 비교 후 절충 설명
- **경로 합계:** 근처 상점 `(4, 5, 1)` / 먼 시장 `(6, 3, 2)` (두 경로 모두 소비 단계 `buyer`로 끝남)
- **승인 경로(복수 정답 둘 다):** 시간·손실 목표에는 근처 상점, 비용 목표에는 먼 시장, 균형 목표는 둘 다 허용 — 계획 문서 4.1의 승인 원칙과 동일
- **조건 변화:** `switch-far-market`, `switch-near-store` (경로 교체형)
- **필요 근거:** `near-wins-time-loss` + `far-wins-cost` — 절충 설명 둘 다 필요
- **오개념 차단:** `near-is-always-safe`(가까우면 무조건 좋음) 금지.

### route-missing-06 · 비용 자료가 빠진 최종 경로

- **학습 행동:** 판단 보류와 필요한 자료 선택
- **경로 합계:** `(6, null, 2)` — 운송 단계 비용 자료 없음
- **유일한 성공 판단:** `insufficient-information` (판단 보류) + 필요 자료로 `transport-cost`(운송비 자료) 선택
- **실패 판단:** 경로를 확정하는 판단(`choose-route`, `keep-route`), 다른 자료(생산 수량, 날씨 기록) 선택
- **오개념 차단:** 자료가 부족한데 추측으로 최종 추천을 하지 않도록 안내.
