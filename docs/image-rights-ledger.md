# 이미지 권리 장부 — 생산·유통 경로 추적소

- 모든 생성 자산은 이 프로젝트를 위해 **코드로 직접 그린 오리지널 SVG 일러스트**를 `scripts/build-assets.mjs`로 webp로 변환한 것이다. 외부 이미지, 핫링크, 실제 상표, 실제 지도, 실제 기업 로고를 사용하지 않는다.
- 이미지 안에 글자·정답·색상만으로 전달되는 정보를 넣지 않았다. 이미지가 로드되지 않아도 제목·지시·선택지·판정·보고서로 활동을 완주할 수 있다.
- 같은 장면을 이미지 생성 모델로 다시 만들 때는 아래 "프롬프트(장면 묘사)"를 그대로 쓰고, 이 표에 새 행을 추가한다.
